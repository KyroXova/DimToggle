## Installation & Deployment

### Dedicated Server
1. Ensure your server is running a supported version of Minecraft with **Fabric**, **Forge**, or **NeoForge**.
2. Download the appropriate JAR file for your Minecraft version and loader from the table above or the [GitHub Releases](https://github.com/KyroXova/DimToggle/releases/latest) page.
3. Place the downloaded `.jar` file into your server's `mods/` directory.
4. Restart your server. The configuration file will generate automatically at `config/dimtoggle.json`.

### Singleplayer / LAN
- DimToggle is server-side and functions in singleplayer / LAN worlds when installed in your client's `mods/` directory.
- Other players connecting to your LAN or multiplayer world do **not** need the mod installed.
