# Security Policy

## Supported Versions

Security updates and critical patches are provided for the active release version:

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x | No |

## Reporting a Vulnerability

If you discover a security vulnerability in DimToggle, please report it responsibly:

* Email details to `kyroxova@gmail.com` with the subject `[SECURITY] DimToggle Vulnerability Report`.
* Alternatively, submit a private vulnerability advisory through GitHub Security Advisories.

Please include:
* A description of the vulnerability and its potential impact.
* Affected Minecraft versions, mod loaders, and DimToggle releases.
* Step-by-step reproduction instructions or proof-of-concept configuration.

We will review your submission promptly, verify the issue, and prepare a patch before public disclosure.
